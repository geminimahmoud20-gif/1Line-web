# نظام التصميم — 1Line

> المرحلة 1 من إعادة تصميم الـ CRM. القرارات اللي صاحب المشروع وافق عليها:
> 1. كحلي 1Line + دهبي للتمييز بس.
> 2. خط Cairo لوحده في كل النظام (اختاره صاحب المشروع بدل Alexandria بعد مقارنة 6 خطوط).
> 3. قائمة جانبية غامقة بس أبسط.
> 4. مكتبة `motion` بتتحمّل مع الـ CRM بس.
>
> تشوف كل المكونات شغالة في: **الـ CRM ← إدارة المنظومة ← مكتبة التصميم** (للمدير العام بس).

## القواعد (لأي حد بيعدّل في الواجهة، إنسان أو AI)

1. **ممنوع لون أو ظل أو استدارة مكتوبين بالإيد.**
   - كل القيم من `src/styles/tokens.css` (`var(--ui-…)`).
   - لو محتاج لون جديد، يتضاف هناك بنسخته الليلية.
   - الاختبار `tests/unit/design-tokens.test.mjs` بيفشل لو لقى لون خام في `src/components/ui`، أو لو نص على خلفية تباينه أقل من 4.5:1.
2. **ممنوع تبني زرار أو كارت أو نافذة أو جدول من الأول.** استورد من `src/components/ui`:
   ```js
   import { Button, Card, Modal, Table, PageHeader } from '../ui';
   ```
   ولو المكوّن ناقصه حاجة، تتضاف للمكوّن نفسه (وتظهر في صفحة مكتبة التصميم)، مش في الشاشة.
3. **الكود القديم في `src/components/crm` مسموح يقل بس، ما يزيدش.**
   - الحدود الحالية: 331 لون hex، و1,624 `style={{}}`، و318 `!important`.
   - أي شاشة بتتنقل للنظام الجديد، الأرقام دي تنزل في نفس الـ PR.
4. **الحقول دايماً ليها label.** `Input` و`Select` و`Textarea` بيطلبوه، و`IconButton` بيطلب `label`.
5. **مفيش `window.confirm`.** استخدم `useConfirm()`:
   ```js
   const confirm = useConfirm();
   if (await confirm({ title: 'حذف العميل؟', message: 'مش هتقدر ترجّعه.', confirmLabel: 'احذف العميل' })) { … }
   ```
6. **الحركة من `motionPresets` بس، وكل شاشة جوه `<MotionRoot>`.** استخدم `m.div` مش `motion.div`، علشان الحجم يفضل صغير.
7. **مفيش إيموجي في الواجهة، ولا شارات إنجليزي زي "360°".** الأيقونات من `lucide-react` بس، بمقاسين 16 و20.

## المكوّنات

| المكوّن | الاستخدام |
|---|---|
| `PageHeader` | رأس كل شاشة: عنوان، ووصف بسطر واحد، والإجراءات، والفلاتر. على الموبايل الوصف بيستخبى والأزرار بتتسحب جنب بعض |
| `Button` | `variant`: primary / secondary / ghost / danger · `size`: sm / md / lg · `loading` · `icon` |
| `IconButton` | زرار أيقونة بس، والـ `label` إجباري |
| `Input` / `Select` / `Textarea` / `Field` | label إجباري، وفيهم `hint` و`error` و`required` |
| `Card` / `CardHeader` | `padding`: default / compact / flush · `interactive` |
| `Badge` / `Chip` / `Count` | tone: neutral / primary / accent / success / warning / danger / info · `dot` للحالة |
| `Tabs` / `SegmentedControl` | بيشتغلوا بالأسهم (ومظبوطين على RTL)، والمؤشر بيتحرك بين العناصر |
| `Modal` | نافذة في النص على الديسكتوب، وبتطلع من تحت على الموبايل. Esc بيقفلها، والتنقل بـ Tab بيفضل جواها، وبعد القفل التركيز بيرجع للزرار اللي فتحها |
| `Drawer` | درج التفاصيل من ناحية نهاية السطر (الشمال في العربي) |
| `ConfirmProvider` + `useConfirm` | تأكيد بزرار اسمه الإجراء نفسه، والتركيز على "إلغاء" في الإجراءات الخطرة |
| `Table` | ترتيب، واختيار متعدد، و`onRowClick`، وskeleton وقت التحميل، وempty state. على الموبايل كل صف بيبقى كارت |
| `KpiTile` / `KpiRow` | رقم بيعدّ لحد قيمته أول مرة يظهر، مع وحدة وتغيّر وخط اتجاه. `value={null}` = "لسه مفيش". على الموبايل الصف بيتسحب أفقي |
| `EmptyState` / `ErrorState` / `Skeleton` | حالة فاضي، وحالة خطأ، وحالة تحميل |
| `Avatar` / `Tooltip` | الحروف الأولى من الاسم، وتلميح يظهر بالماوس أو التركيز |
| `MotionRoot` | بيتحط مرة واحدة حوالين الشاشة |

## اللي اتقاس

- **axe على صفحة مكتبة التصميم** (390 و1366، نهاري وليلي، والنافذة مفتوحة): **صفر** مشاكل.
- **الحقول على الموبايل** كلها 16px.
- **الكيبورد:** Esc بيقفل النافذة والدرج، والتركيز بيفضل جوه النافذة.
- **نافذة التأكيد:** بتفتح والتركيز على "إلغاء".
- **حجم الكود:**
  - الموقع العام ما اتغيرش.
  - كود الـ CRM الأساسي زاد 0.2KB بس.
  - صفحة مكتبة التصميم ومكتبة motion في ملف لوحدهم (حوالي 40KB مضغوط) بيتحمّل لما الصفحة تتفتح.
- **الصور:** `phase1/`.

## الخطوة الجاية (المرحلة 3)

نقل الشاشات واحدة واحدة، بالترتيب ده:
1. الإطار (القائمة والشريط العلوي)
2. صندوق الوارد
3. درج العميل
4. العملاء
5. مسار الصفقات
6. باقي الشاشات

في كل شاشة:
- تتصوّر قبل وبعد.
- أرقام الاختبار في قاعدة 3 تنزل.
- الكلاسات القديمة اللي اتشالت تتمسح من ملفات CSS.
