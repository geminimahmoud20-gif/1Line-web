# 🏛️ One Line Solutions - المنصة العقارية الذكية الأولى بسوهاج 2026

منصة عقارية متكاملة تجمع بين المشترين، البائعين، المستثمرين، والوسطاء المعتمدين في محافظة سوهاج (سوهاج الجديدة، شرق سوهاج، حي الكوثر، وكورنيش النيل)، تحت إشراف **د. محمود الباز**.

## 🌟 الميزات الرئيسية (Key Features)

- 🤖 **المستشار العقاري الذكي (Sohag AI Property Advisor):** محرك محادثة ذكي ومحدث بأسعار السوق والمشورة الاستثمارية والقانونية.
- 📊 **محرك التقييم العقاري المعتمد (AI Property Valuation):** حساب نطاق السعر السوقي العادل وسعر المتر بدقة فائقة.
- 🏗️ **دليل المشروعات الكبرى والكمبوندات (Flagship Projects):** متابعة حية لنسب التنفيذ الإنشائي الميداني وتحميل الكتالوجات PDF.
- ⚖️ **مصفوفة المقارنة التفاعلية (3-Property Comparison Matrix):** مقارنة تفصيلية للمواصفات والأسعار والأقساط.
- 📈 **مركز المستثمرين (VIP Investor Center):** محاكاة العوائد الرأسمالية والإيجارية التراكمية (ROI).
- 🔒 **الخزينة العقارية السرية (Off-Market Vault):** صفقات حصرية واستثنائية لكبار العملاء.
- 🛡️ **لوحة تحكم المشرف (CRM Admin Dashboard):** تتبع العملاء والطلبات وتصدير ملفات Excel بنقرة واحدة وإدارة العقارات.

## 🚀 التشغيل السريع (Quick Start)

### المتطلبات
- Node.js (v18+)
- npm أو yarn

### التثبيت والتشغيل محلياً
```bash
# 1. تثبيت الحزم البرمجية
npm install

# 2. تشغيل خادم التطوير المحلي
npm run dev
```

### بناء نسخة الإنتاج (Production Build)
```bash
npm run build
```

## 🔒 الأمان والتشفير (Enterprise Security)
- تشفير كلمات المرور باستخدام خوارزمية **Salted SHA-256 Crypto**.
- حماية ضد هجمات التخمين الآلي **Anti-Brute-Force Rate Limiter**.
- تعقيم وتطهير المدخلات بواسطة **DOMPurify**.
- ترويسات أمان متقدمة وحماية ضد الـ **Clickjacking** و **XSS**.
- قواعد أمان سحابية **Google Firebase Firestore Rules**.
